# 🍽️ Dastarkhwan Restaurant

A modern and responsive restaurant website built using HTML5 and CSS3.

## 🚀 Features
- Clean and attractive UI
- Responsive design
- Food menu section
- User-friendly layout
- Modern styling

## 🛠️ Technologies Used
- HTML5
- CSS3
- Flexbox
- Media Queries

## 🎯 Purpose
This project was developed to practice frontend development skills and gain hands-on experience in building responsive websites.
